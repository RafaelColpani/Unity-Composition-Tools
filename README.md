
# Composition Tools

A collection of composition guides for Unity.

## Features

- Rule of Thirds
- Letterbox with custom aspect ratios
- Action Safe (95% default)
- Custom guide colors
- Adjustable line thickness
- Debug information

## Requirements

- Unity 6.0 or newer
- Unity Package Manager

## Installation

Install using Unity Package Manager:

1. Open Window > Package Management > Package Manager.
2. Click the + button.
3. Select Add package from git URL.
4. Enter the repository URL.

## Usage

Open:

Tools > Composition > Rule of Thirds

Select your Game Camera and enable the overlay.
